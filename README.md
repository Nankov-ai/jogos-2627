# Jogos 26.27

Página estática com o calendário de jogos de uma equipa Sub-11 (época 2026/27). Cada pessoa escolhe o jogo
da convocatória e adiciona-o ao seu Google Calendar.

- Sem servidor, sem contas, sem cookies, sem analytics e sem recolha de dados.
- As marcações ficam apenas no armazenamento local do telemóvel de cada pessoa.
- Os horários são copiados do calendário oficial da AFL e podem mudar: confirmar sempre no site oficial.

## Segurança
Para comunicar um problema de segurança, usar o separador *Security* do repositório (relatório privado).
